## 分镜详细表

### Shot 01｜停一下，看看今天的自己

| 项目 | 内容 |
|---|---|
| 时长 | ~12s |
| 旁白 | 上一集我们知道了，有些情绪可以画出来。今天我们来试试第一个练习——在开始之前，先停一下。问问自己：今天的我，感觉怎么样？ |
| 画面 | 白板上出现一个简单的小人，坐在桌前，面前放着纸和彩色笔。小人抬头，表情从茫然转为好奇。 |
| 动画重点 | 小人的表情变化——从日常状态切换到"向内觉察"的状态。 |
| 关键文字 | 今天的我，感觉怎么样？ |

### Shot 02｜心情可以是什么颜色

| 项目 | 内容 |
|---|---|
| 时长 | ~10s |
| 旁白 | 现在，想象一下：如果今天的心情是一种颜色，它会是什么颜色？是蓝色的平静？还是橙色的活力？或者是几种颜色混在一起？ |
| 画面 | 白板上依次出现几个彩色色块：蓝色（平静）、橙色（活力）、灰色（疲惫）、粉色（温暖）。每个色块旁边有简单的文字标签。 |
| 动画重点 | 色块一个接一个出现，像在给观众提供选项，但不做评判。 |
| 关键文字 | 心情 = 颜色？ |

### Shot 03｜没有正确答案

| 项目 | 内容 |
|---|---|
| 时长 | ~10s |
| 旁白 | 记住，这里没有正确答案。不需要想"应该是什么颜色"，只需要感受：此刻的你，是什么颜色。想到了吗？ |
| 画面 | 白板中央出现一个大大的问号，周围是各种颜色的问号。然后问号逐渐消散，留下一句话："没有正确答案"。 |
| 动画重点 | 从"选择困难"到"放下评判"的视觉转变。 |
| 关键文字 | 没有正确答案 |

### Shot 04｜让颜色留下痕迹

| 项目 | 内容 |
|---|---|
| 时长 | ~10s |
| 旁白 | 好，现在拿起你选的那支笔。在纸上随便画一画、涂一涂。可以是线条，可以是色块，让这种颜色在纸上留下痕迹。 |
| 画面 | 一只手拿起一支彩色笔（比如蓝色），在纸上开始画。线条从简单到丰富，色块逐渐铺开。 |
| 动画重点 | 手的动作——从犹豫到自然，线条从拘谨到放松。 |
| 关键文字 | 画一画 |

### Shot 05｜这不是美术考试

| 项目 | 内容 |
|---|---|
| 时长 | ~10s |
| 旁白 | 不用担心画得好不好看。这不是美术考试，没有人会打分。重要的不是画面，而是你在涂画的时候，感受到了什么。 |
| 画面 | 白板上出现一张"试卷"的轮廓，上面有打分栏。然后试卷被划掉（一个大大的×），换成一张随意的涂鸦。 |
| 动画重点 | 从"考试压力"到"自由表达"的视觉释放。 |
| 关键文字 | 不是美术考试 |

### Shot 06｜还有别的颜色吗

| 项目 | 内容 |
|---|---|
| 时长 | ~10s |
| 旁白 | 涂着涂着，你可能会发现：今天的心情，好像不只有一种颜色。没关系，再选一支笔，把另一种感受也画出来。 |
| 画面 | 纸上已经有了一种颜色（比如蓝色）。然后另一只手拿起另一支笔（比如橙色），在蓝色旁边开始画。两种颜色并存。 |
| 动画重点 | 从单一颜色到多颜色的扩展——情绪的复杂性被允许。 |
| 关键文字 | 还有别的颜色吗？ |

### Shot 07｜让颜色彼此相遇

| 项目 | 内容 |
|---|---|
| 时长 | ~10s |
| 旁白 | 让这些颜色在纸上相遇。它们可以重叠，可以交错，就像我们的情绪一样，常常是好几种感受混在一起。 |
| 画面 | 纸上的多种颜色开始重叠、交错。蓝色和橙色混合的地方出现了新的颜色（比如棕色或紫色）。画面变得丰富而和谐。 |
| 动画重点 | 颜色的融合——不是冲突，而是创造新的可能。 |
| 关键文字 | 让颜色相遇 |

### Shot 08｜停下来看一看

| 项目 | 内容 |
|---|---|
| 时长 | ~10s |
| 旁白 | 好了，现在停下来。看着你画的这张纸，这些颜色，就是你今天的心情。你能认出它们吗？ |
| 画面 | 手放下笔。镜头拉远，展示完整的画面——一张充满颜色的纸。小人看着这张纸，表情从专注变为温柔。 |
| 动画重点 | 从"创作"到"观照"的切换——停下来，看见自己。 |
| 关键文字 | 停下来，看一看 |

### Shot 09｜被看见

| 项目 | 内容 |
|---|---|
| 时长 | ~11s |
| 旁白 | 当你把心情画出来，它就不再是一团说不清楚的感觉了。它被看见了——被你自己看见。这就是艺术疗愈的开始。下一节课，我们继续。 |
| 画面 | 纸上的颜色逐渐发光，形成一个温暖的光晕。光晕中出现一颗心的形状。然后画面定格，出现课程标题和下一集预告。 |
| 动画重点 | 从"混乱的情绪"到"被看见的温暖"——整个课程的核心隐喻。 |
| 关键文字 | 被看见 |

## 视觉风格统一

- **风格**：白板手绘 + 蜡笔/马克笔质感
- **配色**：温暖、柔和，以彩色笔的自然颜色为主
- **节奏**：舒缓、从容，给观众留出感受的时间
- **文字**：简洁、温暖，不超过画面的 20%
- **人物**：简单的线条小人，表情细腻但不夸张

## 音频设计

- **旁白**：于颖老师温柔女声，语速适中，有停顿
- **背景音乐**：轻柔的钢琴曲或吉他曲，音量低于旁白
- **环境声**：画笔在纸上的沙沙声（保留）
- **静音段**：翻页转场 2 秒完全静音，制造呼吸感
