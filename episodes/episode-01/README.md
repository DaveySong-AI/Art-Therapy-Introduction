# 第 1 课：给今天的心情一种颜色

> 艺术疗愈 · 10 节课系列

## 课程简介

这是艺术疗愈系列的第一节正式练习课。我们不教绘画技巧，而是用一个最简单的练习——**给今天的心情选一种颜色**——帮助你开始觉察自己的情绪。

**核心句：** 没有正确答案，只有属于你的答案。
