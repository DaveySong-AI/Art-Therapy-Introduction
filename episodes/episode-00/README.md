## 视频参数

- **时长：** 60 秒
- **分辨率：** 1280×720（16:9）
- **帧率：** 24fps
- **旁白：** 温柔女声
- **背景音乐：** 轻柔钢琴 + 弦乐（音量 18%）
- **风格：** 白板手绘动画，黑白线条为主 + 关键情绪点彩色点缀
