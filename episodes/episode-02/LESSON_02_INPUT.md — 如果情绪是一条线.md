# 1. 本集定位

Lesson 01 已经带观众完成了第一步：

> **给今天的心情一种颜色。**

它解决的是：

> **我现在有什么感觉？**

Lesson 02 在此基础上继续向前一步。

我们不再只问：

> “它是什么颜色？”

而开始观察：

> **“这种感觉，是怎么动的？”**

情绪有时会让人感觉：

- 慢慢的；
- 急急的；
- 很轻；
- 很重；
- 一直往前；
- 来回绕；
- 忽然改变方向；
- 一会儿紧，一会儿松。

这些体验不一定需要先变成准确的语言。

它们可以先变成：

# 一条线。

因此 Lesson 02 是从：

**Emotion Awareness / 情绪觉察**

进一步进入：

**Non-verbal Expression / 非语言表达**

---

# 2. Lesson 01 → Lesson 02 的课程递进

Lesson 01：

> **我现在是什么感觉？**

艺术语言：

> COLOR / 颜色

核心动作：

> Notice → Choose → Create → Observe

---

Lesson 02：

> **我的这种感觉是什么样子的？**

艺术语言：

> LINE / 线条

核心动作：

> Feel → Move → Draw → Observe

即：

> **感受 → 运动 → 留下线条 → 观察**

---

开场必须自然承接 Lesson 01。

不是传统网课式：

> “上一节课我们学习了情绪色彩画，今天学习情绪线条画。”

而是：

> 上一节课，  
> 我们给心情选了一种颜色。
>
> 今天，  
> 我们再往前走一步。
>
> 如果你的情绪，  
> 变成一条线……
>
> **它会怎么动？**

画面同步完成：

**Lesson 01 的颜色点**

↓

**真实笔尖接触颜色点**

↓

**手开始移动**

↓

**颜色从笔尖后方逐渐延伸**

↓

**成为 Lesson 02 的第一条线**

这是本集第一个重要 Visual Bridge。

# 3. 本集教学目标

观看 Lesson 02 后，观众应该能够：

1. 注意自己的感受不仅可以有颜色，也可能有速度、力度和节奏；
2. 用手的运动和线条表达此刻的感受；
3. 尝试体验线条的：
   - 快 / 慢；
   - 轻 / 重；
   - 直 / 弯；
   - 松 / 紧；
   - 连续 / 停顿；
   - 改变方向；
4. 理解“同一种感觉”可以被不同的人画成完全不同的线；
5. 在完成以后观察自己的线，而不是急着解释它代表什么；
6. 理解艺术表达没有唯一标准答案。

---

# 4. 本集不做什么

本集**不是**：

- 情绪线条标准教学；
- 绘画技巧课；
- 笔触训练课；
- 心理测验；
- 根据线条判断人格；
- 根据线条诊断心理问题；
- 教孩子“正确地画生气、开心、焦虑”。

禁止建立以下固定规则：

> 锯齿线 = 生气

> 波浪线 = 平静

> 黑线 = 难过

> 圆圈 = 焦虑

这些只能作为：

> **某个人可能的表达方式。**

不能作为：

> **标准答案。**

---

# 5. Core Message

本集核心句：

> **当语言找不到的时候，让线条替你说话。**

辅助概念：

> 线条没有标准答案。

> 同一种感觉，每个人都可以画得不一样。

> 不需要先知道它代表什么。

> 先让手动起来。

---

# 6. Art Method

## Emotional Line Drawing

中文：

## 情绪线条画

材料：

- 一张白纸；
- 一支自己愿意使用的彩笔、蜡笔、彩铅或马克笔；
- 可以继续使用 Lesson 01 中吸引自己的颜色；
- 也可以重新选择一种颜色。

不要求：

- 直尺；
- 专业绘画工具；
- 画具体物体；
- 把作品画漂亮。

核心规则：

> **让线跟着感觉走。**

而不是：

> 让感觉跟着“正确线条”走。

---

# 7. Hero Visual

本集唯一必须重点保护的 Hero Visual：

# 一支笔真正接触纸面以后，手的运动发生变化，而一条线始终只从笔尖后方生长出来。

视觉过程：

**一个颜色点**

↓

**笔尖接触**

↓

**一条很慢的线**

↓

**速度发生变化**

↓

**手的力度发生变化**

↓

**方向开始改变**

↓

**线条留下不同的节奏**

↓

**形成一条只属于此刻感受的线**

Hero Visual 的重点不是：

> “画出漂亮线条。”

而是：

> **手的动作第一次成为情绪表达的一部分。**

# 8. 视觉母题

Lesson 01 的视觉主角是：

# COLOR

Lesson 02 的视觉主角变成：

# MOVEMENT + LINE

因此本集画面应该明显比 Lesson 01 更有：

- 运动；
- 节奏；
- 速度变化；
- 手部动作；
- 笔与纸的真实接触感。

但仍然保持：

- 白色背景；
- 大量留白；
- 简洁；
- 温暖；
- 不拥挤；
- 不幼稚。

# 9. Narration Writing Rules

从 Lesson 02 开始，旁白正式采用：

## Short Semantic Beat

即：

> **一段声音 = 一个完整的小意思。**

目的：

- 方便克隆声音；
- 方便数字人口型同步；
- 方便 SRT；
- 方便视频分镜卡点；
- 方便后期单独调整某一句。

避免长句。

例如不写：

> 线条可以很快也可以很慢，可以很重也可以很轻，而且每个人画出来都不一样。

拆成：

> 有时候，线会很慢。

> 有时候，它会突然变快。

> 它可以很轻。

> 也可以，很有力量。

原则：

# 短句 ≠ 碎句

必须保留自然语气和完整语义。

## Storyboard Image Prompt

白板手绘动画风格，温暖简洁、适合 8–18 岁儿童青少年。干净纯白背景，大量留白。画面左上区域有简洁友好的于颖老师手绘形象识别，不幼儿化；右侧是一张横向白纸，纸面上只有一个带真实蜡笔纹理的蓝紫色小色点，像是上一节课留下的颜色。真实女性右手拿着同色蜡笔停在纸边，准备继续绘制。黑色自然手绘线稿为主，仅保留柔和蓝紫色点彩。16:9，无任何 AI 生成中文文字，无复杂背景，无 3D。

## Video Prompt — Timeline Execution

**单一固定镜头。镜头视角保持稳定，不切镜，不变焦。**

**0.0–2.2 秒：**  
画面左侧简洁的于颖老师手绘形象已经存在，只做非常轻微的眨眼和呼吸，不重新绘制人物。画面右侧保持干净白色。

**2.2–4.2 秒：**  
于颖老师保持微笑。无其他动作。

**4.2–7.5 秒：**  
一只真实右手从画面下方进入，手里拿着蓝紫色蜡笔。笔尖在右侧白纸中央轻点一次，只留下一个小小的蓝紫色颜色点。颜色只在笔尖与纸面真实接触的位置出现。

**7.5–10.2 秒：**  
手稍微离开纸面，在颜色点右侧停住，像准备继续画。颜色点保持完全静止，不扩散、不自动变化。

**镜头锁定：**  
全程单一镜头。固定机位。无推拉。无摇镜。无景深变化。

**绘制因果：**  
任何颜色只能在蜡笔笔尖实际接触纸面后出现。禁止颜色自动生成。

**声音：**  
蜡笔轻点纸面时只有一次非常轻的“嗒”与短促纸面摩擦声。不要生成旁白。不要生成音乐。

# 27. Grok Imagine / 多平台 Video Prompt 规则

Lesson 02 开始采用以下新标准。

每一个 Prompt 最好按：

## 1. Shot Type

先明确：

> 单一固定俯视镜头。

或者：

> 单一固定平视镜头。

禁止同时提出多个机位。

---

## 2. Initial State

必须明确：

> 第一帧有什么？

例如：

> 白纸完全空白。

而不是只描述最终画面。

---

## 3. Timeline

使用：

> 0.0–1.0 秒  
> 1.0–3.5 秒  
> 3.5–6.0 秒

不要只写：

> 首先……然后……最后……

时间越具体，Grok Imagine 越容易理解动作顺序。

---

## 4. Physical Causality

所有白板绘制 Prompt 必须明确：

> **线条只能出现在正在移动的笔尖后方。**

禁止只写：

> “线条逐笔出现。”

---

## 5. One Main Action

每个 Clip 原则上只完成：

一个主要动作。

复杂镜头拆分。

例如：

不要一个 Clip 同时要求：

> 画四种线 + 人物眨眼 + 摄像机移动 + Logo 出现 + 字幕 + 声音。

---

## 6. Explicit End State

每个 Prompt 最后明确：

> 手停止。

> 抬笔。

> 作品保持静止。

否则模型容易继续创造新内容。

---

## 7. Sound Lock

视频生成阶段只生成：

- marker-on-paper；
- crayon-on-paper；
- 轻微 tap；
- 必要自然拟音。

不要让模型生成：

- 于颖老师旁白；
- BGM；
- 中文对白；
- 环境人声。

旁白和音乐统一后期制作。

> 较明显但不刺耳的“刷——”

轻点纸面：

> “嗒”

抬笔：

> 摩擦声立即停止。

禁止：

- Cartoon Boing；
- Whoosh 滥用；
- 游戏音效；
- 夸张爆炸声音。

- 极简；
- 轻柔 Piano + Ambient；
- 不煽情；
- 不制造“心理治疗”神秘感；
- 不压过纸面声音。

建议：

旁白期间约：

# 12–16%

Hero Drawing / Silence Window：

可以轻微降低音乐。

让：

# crayon-on-paper

成为声音主角。

# 34. Safety / Psychological Guardrails

不得说：

> “从你的线可以看出你的心理状态。”

不得说：

> “画锯齿说明你很愤怒。”

不得说：

> “乱线代表焦虑。”

不得说：

> “如果画得很重，说明压力很大。”

正确表达：

> “你可以试试看。”

> “它可能是这个样子。”

> “也可能完全不一样。”

> “你的线不需要和别人一样。”

> “不需要马上解释它。”

# 37. Voice Production Recommendation

不要优先生成一条连续 100 秒 TTS。

建议：

# 按 Voice Segment 或 Shot 生成

例如：

`voice-01.wav`

`voice-02.wav`

……

然后按照：

SRT Start Time

放入 Master Timeline。

好处：

- 某一句口型失败只重做一句；
- 某一句语速过快只重做一句；
- 某句情绪不对不影响整条旁白；
- 方便数字人；
- 方便不同 TTS 平台替换；
- 不会出现整段声音累计漂移。

# 39. North Star

Lesson 02 最重要的画面不是：

> 四种漂亮的情绪线条。

而是：

# 一只手停了一下，然后开始移动。

线条随着：

- 速度；
- 力度；
- 方向；
- 节奏；

一点一点留在纸上。

最后孩子看着它。

没有人告诉他：

> “这是什么意思。”

老师只是说：

> **这是你现在，留在纸上的一条线。**

观众看完以后最理想的反应应该是：

> “原来不用知道要画什么。”

> “我可以先让手动起来。”

以及：

# “我的感觉，也许真的可以变成一条线。”
