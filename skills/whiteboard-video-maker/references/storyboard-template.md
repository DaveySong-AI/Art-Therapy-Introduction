# 分镜表模板

## 使用方式
按旁白时间线逐行填写，每个镜头一行。确认所有镜头后再生成分镜图。

## 空白模板

| 镜头 | 时间段 | 旁白内容 | 画面元素 | 动画重点 | 彩色运用 |
|---|---|---|---|---|---|
| 1 | 0–Xs | | | | |
| 2 | X–Xs | | | | |
| 3 | X–Xs | | | | |

## 字段说明

- **时间段**：该镜头的起止时间，单镜头 5–12 秒
- **旁白内容**：该时间段对应的旁白原文
- **画面元素**：白板上出现的所有视觉元素，按出现顺序列出
- **动画重点**：元素如何出现（逐笔画出/逐个堆积/从A延伸到B），强调"不是一次性出现"
- **彩色运用**：哪些元素用彩色、什么颜色，其余保持黑白线条

## 检查清单

分镜表完成后，逐项确认：
- [ ] 所有镜头时间段加起来等于总时长
- [ ] 每个镜头旁白内容完整，无遗漏
- [ ] 每个镜头画面元素具体，不是模糊描述
- [ ] 动画重点明确"如何出现"，不是"出现什么"
- [ ] 彩色运用点明确，全片彩色点不超过 3–5 处（保持黑白为主的风格）
- [ ] 有关键文字的镜头，文字内容已明确写出（避免AI生成时写错）
