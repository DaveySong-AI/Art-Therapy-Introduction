# Prompt 模板库

## 一、分镜图生成 Prompt（image_gen）

### 通用前缀（所有分镜图共用）
```
白板手绘动画风格，黑白线条为主关键情绪点彩色点缀，一只手拿着黑色马克笔在白色白板上绘制，
```

### 通用后缀（所有分镜图共用）
```
面向儿童青少年的简洁卡通画风，干净白色背景，真实手部特写，16:9横版构图
```

### 完整结构
```
[通用前缀] + [该镜头的具体画面描述] + [通用后缀]
```

### 各镜头描述写法

**镜头1（压力堆积类）：**
```
画面中央是一个简单的卡通小人，表情疲惫耷拉着眼皮。小人头顶从下往上依次堆积着：一叠工作文件、一部手机、一个时钟、一个感叹号、一团越来越乱的黑色线条。最上方画着一个红色的低电量电池图标，电池内部只有最左侧一小格红色，其余为空，表现亏电状态。
```

**镜头2（情绪表达类）：**
```
画面中央是一个人的正面头像轮廓，脑袋里面画着一团极度凌乱的线，夹杂着波浪线、叉号、三角形、圆形等混乱符号，乱线中有一点点蓝色和紫色点缀。头像右侧有一个白色对话框，对话框里用淡灰色写着两个字：没事。字上方有省略号表示欲言又止。
```

**镜头3（视觉转折类）：**
```
画面左侧是一个简化人头侧面轮廓，从脑袋中延伸出一团黑色乱线。一只手拿着画笔，把这团线从左向右慢慢画到一张白纸上。纸上的线条从混乱黑线逐渐演化：波浪线、圆形、然后是温暖的彩色色块（柔和橙色、黄色、蓝色、绿色涂抹），最终形成一幅简单的抽象画。画面右上角有三个清晰的黑色大字：画出来。
```

**镜头4（概念解释类）：**
```
画面正中央是一张白纸。纸的周围四个方向各有一个元素：上方是波浪线图标配文字线条 LINE，右侧是一个彩色调色盘配文字颜色 COLOR，下方是几何图形组合配文字形状 SHAPE，左侧是灯泡图标配文字创造 CREATE。四个元素各有一条黑色箭头汇入中央白纸。从白纸上方再画出一条箭头指向一颗粉红色的心形，心旁边写着：表达 看见 理解。
```

**镜头5（对比类）：**
```
左右对比构图。左边：一个精致逼真的红苹果，旁边写着画得好，下面一个红色叉号。右边：几根简单的涂鸦线条和几个随意的彩色色块（橙色、蓝色、绿色涂抹），旁边写着我的感受，下面一个绿色对勾。画面底部中央出现一行温暖鼓励的大字：不需要会画画。
```

**镜头6（前后呼应类）：**
```
画面中央是一个卡通小人，头顶有一团乱线和一些变淡的压力元素（文件、手机、时钟）。小人面前放着一张白纸。小人用双手把头顶那团乱线拿下来放到面前的纸上。随着乱线从脑袋移到纸上，头顶压力元素逐渐变淡消失，脑袋周围变得干净清爽。小人表情放松微笑，旁边用浅蓝色气流线条画一个呼气符号：呼。
```

**镜头7（结尾定格式）：**
```
一只手在白板上从左下角画出一条蜿蜒的黑色线条，这条线向上延伸逐渐变成一颗粉红色的心形，心有温暖的橙粉色渐变。然后在心的外面用黑色线条画一个圆圈包围住它。画面中央偏上位置两行文字：第一行艺术疗愈 · 10节课，第二行小字从一支笔开始，看见自己。底部出现 LESSON 01 加一个向右箭头。
```

## 二、视频片段生成 Prompt（image_to_video）

### 通用结构
```
白板手绘动画效果。一只手拿着[笔的类型]在白色白板上逐笔绘制。[该镜头的动态过程描述，强调元素逐笔出现，不是一次性显示]。镜头固定平视白板，干净白色背景，[风格描述]。
```

### 动态过程描述要点
- 必须写"首先画出...然后...接着...最后..."的顺序
- 强调"一笔一笔逐渐画出来，不是一次性出现"
- 描述手的动作（拿着马克笔绘制、拿着画笔涂抹等）
- 描述元素出现的先后顺序

### 示例（镜头1）
```
白板手绘动画效果。一只手拿着黑色马克笔在白色白板上逐笔绘制。首先画出一个简单的卡通小人轮廓，表情疲惫。然后小人头顶依次出现：一叠工作文件、一部手机、一个时钟、一个感叹号、一团越来越乱的黑色线条。最后顶部出现一个红色的低电量电池图标，电池内部只有最左侧一小格红色，其余为空。所有元素都是一笔一笔逐渐画出来的，不是一次性出现。镜头固定平视白板，干净白色背景，黑白线条为主红色点缀，面向儿童青少年的简洁风格。
```
