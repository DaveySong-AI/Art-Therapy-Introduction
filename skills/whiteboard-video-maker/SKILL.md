# 白板手绘视频制作

## 输入与输出

### 必须输入
- **脚本/旁白文案**：完整的旁白文字，或主题+时长由本技能起草
- **目标受众**：如儿童青少年、成人、商务人士等（影响画风和语言）

### 可选输入（有默认值）
- **风格**：默认黑白线条为主+关键情绪点彩色点缀；可选纯黑白、全彩色、粉笔黑板风、水彩风、极简扁平风
- **时长**：默认 60 秒；视频生成工具单段最长 15 秒，需拆分镜头
- **分辨率**：默认 1280×720（16:9）；优化可选 854×480
- **旁白音色**：默认温柔女声；可选沉稳男声、活力女声等
- **是否去水印**：默认需要去水印

### 输出
- 一个完整的 MP4 视频文件（含旁白+背景音乐，已去水印）
- 保存在用户指定目录或当前项目目录下

## 工作流程

严格按以下 7 步执行，不得跳步：

### 第 1 步：需求确认与脚本定稿
- 如果用户只给了主题，先起草旁白脚本并请用户确认
- 脚本按句子拆分为镜头，每个镜头 5–12 秒
- 确认风格、时长、受众、音色

### 第 2 步：分镜设计
- 按旁白时间线拆分镜头，填写分镜表（模板见 `references/storyboard-template.md`）
- 每个镜头明确：时间段、旁白内容、画面元素、动画重点、彩色运用点
- 镜头数量 = 总时长 / 平均 8 秒，60 秒视频约 7 个镜头

### 第 3 步：生成分镜图
- 用 `image_gen` 为每个镜头生成一张分镜关键帧图
- 统一 prompt 前缀：`白板手绘动画风格，[风格描述]，一只手拿着马克笔在白色白板上绘制，`
- 分辨率统一 2048×1152（16:9）
- **关键**：所有分镜图一次性批量生成，生成后逐张检查，有问题（文字错误、元素缺失）立即修正，**确认全部正确后再进入下一步**，避免后续视频重制

### 第 4 步：生成视频片段
- 用 `image_to_video` 以每张分镜图为参考，生成对应镜头的视频片段
- 模型默认 `seedance_2.0_fast`（最经济），不要用 2.0/2.5
- 每段时长 = 该镜头的时间长度（5–12 秒）
- prompt 描述手绘动画效果：元素逐笔出现，不是一次性显示
- 一次最多生成 2 段，分批生成
- 所有片段下载到同一工作目录，命名 clip1.mp4、clip2.mp4...

### 第 5 步：生成音频
- **旁白**：用 `text_to_audio_plus` 生成完整旁白，duration = 视频总时长
- **背景音乐**：用 `text_to_audio_plus` 生成轻柔背景音乐，duration = 视频总时长，prompt 强调"音量轻柔不抢人声"
- 两个音频可并行生成

### 第 6 步：拼接与合成
用 ffmpeg 完成以下操作（命令参考见 `references/ffmpeg-guide.md`）：

1. **拼接视频**：创建 concat.txt 列出所有 clip，用 `ffmpeg -f concat` 拼接
2. **混合音频**：旁白音量 1.0，背景音乐音量 0.18，用 `amix` 混合
3. **合并音视频**：将混合音频与拼接视频合并，`-t` 裁剪到总时长
4. **音频编码**：AAC 192kbps

### 第 7 步：去水印与验证
- AI 生成的视频通常带"豆包AI生成"水印，**可能在左上角，也可能在右下角，甚至动态切换**
- 用 `delogo` 滤镜**同时处理左上角和右下角两个区域**：
  `delogo=x=10:y=10:w=220:h=80,delogo=x=1030:y=635:w=235:h=75`
- 去水印后**必须抽至少 4 个时间点的帧**（如 5s/20s/40s/55s）逐张检查，确认两个角落都无残留
- 验证通过后交付

## 关键注意事项（踩过的坑）

1. **分镜图文字易错**：AI 生成图片中的文字经常写错，必须逐张检查，错了立即用 `image_edit` 修正，不要带着错误分镜图去生成视频
2. **水印位置不固定**：不要只检查一帧就判断水印位置，必须抽多个时间点确认；去水印时两个角落都要处理
3. **避免视频重制**：视频生成是消耗最大的环节，分镜图阶段务必确认所有细节（包括电池状态这种小细节），再批量生成视频
4. **视频时长上限**：`image_to_video` 单段最长 15 秒，超过必须拆分镜头
5. **TTS 时长匹配**：旁白音频 duration 必须与视频总时长一致，否则合成时会截断或留白
6. **ffmpeg concat 要求**：所有 clip 必须编码格式、分辨率、帧率完全一致（都是同一工具生成的就没问题）

## 优化建议（降低积分消耗）

按收益从大到小：

1. **避免重制**：分镜图确认无误再生成视频，这是最大的节省
2. **降低分辨率**：1280×720 → 854×480，白板线条风格画质损失不明显，消耗显著降低
3. **减少风格参考图**：不要每次都生成 5 张风格参考图，确认风格后直接说"用之前的风格"
4. **紧凑镜头时长**：简单镜头（如结尾定格）缩短到 3–5 秒，不要每段都 8–10 秒
5. **始终用 fast 模型**：`seedance_2.0_fast` 对白板风格完全够用，不要升级模型
